### 🛠️ Technologies Used

1. Next.js ⚛️
2. Hero UI 🎨
3. JavaScript (ES6) ✨
4. Tailwind CSS 💨
5. React Icons 🎯
6. React Toastify 🔔
7. Better Auth 🔐
8. MongoDB 🍃
9. Swiper 📱

🔥 **Key Features:**
🔹 Saw destinations and add destination 🤖
🔹 Fast and smooth user experience ⚡
🔹 Clean and modern UI 🎨
🔹 You can add booking destination
🔹 Easy-to signUp and login (Google login also working)
🔹 Fully responsive

You can saw easily your favarit location. Also add them and see them, edit destination, delete destination 🗺️
